## CRITICAL (3)

### CR-1. Production docker-compose — yanlış PostgreSQL image
**Dosya:** `docker-compose.yml:16`
**Sorun:** `postgres:16-alpine` kullanılıyor ama migration `0038_add_pgvector_rag.sql` vector extension gerektiriyor. Dev compose doğru olarak `pgvector/pgvector:pg16` kullanıyor.
**Etki:** Production deploy migration'da çöker.
**Çözüm:** `postgres:16-alpine` → `pgvector/pgvector:pg16`

### CR-2. Graceful shutdown yok — DB pool kapanmıyor
**Dosya:** `backend/src/server.ts`, `backend/src/db/client.ts`
**Sorun:** SIGTERM/SIGINT handler'ı yok. `app.close()` hiç çağrılmıyor. Pool connection'lar zombie olarak PostgreSQL'de kalıyor.
**Etki:** Deploy sırasında in-flight pipeline write'ları corrupt olabilir.
**Çözüm:** Signal handler + `onClose` hook + pool.end()

### CR-3. PORT env var mismatch
**Dosya:** `docker-compose.yml:54` + `backend/src/config/env.ts:40`
**Sorun:** docker-compose `PORT: 3000` set ediyor ama backend `AKIS_PORT` okuyor. `PORT` tamamen ignore ediliyor.
**Çözüm:** `PORT` → `AKIS_PORT` veya env schema'ya alias ekle

## HIGH (4)

### H-1. Cookie SameSite=None zorlaması (CSRF riski)
**Dosya:** `backend/src/lib/env.ts:17`
**Sorun:** `AUTH_COOKIE_SECURE=true` olduğunda SameSite otomatik `None` oluyor — en az kısıtlayıcı seçenek. Same-origin Caddy deploy için `Lax` olmalı.
**Çözüm:** Override mantığını kaldır, `AUTH_COOKIE_SAMESITE` direkt kullan.

### H-2. Dead cookie decorator — aktif manual opts ile drift riski
**Dosya:** `backend/src/plugins/security/cookies.ts`
**Sorun:** `reply.setAuthCookie()` decorator tanımlı ama hiç çağrılmıyor. Auth route'ları `lib/env.ts`'den manual cookie options kullanıyor.
**Çözüm:** Ya decorator kullan ya da kaldır.

### H-3. OAuth HMAC hardcoded fallback key
**Dosya:** `backend/src/api/auth.oauth.ts:52`
**Sorun:** `AUTH_JWT_SECRET` undefined ise `'dev-oauth-state-key'` kullanılıyor. Saldırgan OAuth state token forge edebilir.
**Çözüm:** Fallback yerine throw Error.

### H-4. Logger dotenv'den önce initialize oluyor
**Dosya:** `backend/src/lib/logger.ts`
**Sorun:** `LOG_LEVEL` .env'den okunmuyor çünkü logger module-level'da dotenv'den önce yükleniyor.
**Çözüm:** Lazy init veya early dotenv load.
